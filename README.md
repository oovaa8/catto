# Complete and Total Terrain Overhaul (CATTO)
Minecraft mod that overhauls overworld terrain generation giving it a much larger scale and adding new biomes

## Recommended Mods
I recommend using c2me and c2me opencl to speed up terrain generation as the cpu generetaion for this mod is very slow

## Compatibility
This mod has patches for:
  C2ME OpenCl Acceleration
  Blooming Biosphere
This mod is incompatible with any mods that change terrain generation (Tectonic, JJThunder To The Max...)
Mods that add biomes will work if you use a mod like Biolith but may look weird as this makes minor changes to vanilla biome mappings

## Erosion
The erosion in this mod is made using Runevision's erosion filter you can find the original here: https://www.shadertoy.com/view/sf23W1 \
Also check out Runevision's youtube channel: https://www.youtube.com/@runevision and blog post about this technique: https://blog.runevision.com/2026/03/fast-and-gorgeous-erosion-filter.html
